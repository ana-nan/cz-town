# 创智小镇 · 创智龙广场

React + TypeScript + Vite 前端演示。品牌为「创智小镇」，场景地点为「创智龙广场」。

## 本地运行

```sh
npm install
npm run dev -- --port 5173
```

访问 http://127.0.0.1:5173/ 。生产构建使用 `npm run build`，输出在 `dist/`。

## 当前体验

- 全屏纸片下沉广场：四个入口、基础漫游、换装、聊天气泡。
- 心情驿站：心情打卡、参与或取消活动。
- 匿名开麦：发帖及回复使用统一匿名展示，不显示角色装扮。
- 小镇公告：前沿信号、活动海报分类。
- 漂流瓶：随机捞取分享、投递、回复。
- 首次进入弹出日报；未读按帖子正文和回复数量记录。阅读详情标记单条已读，也可全部标为已读。关闭日报不会自动清除未读。
- 每个入口显示最近消息；右上角可重新打开日报。
- 枝叶、飞鸟、小猫呼吸、蝴蝶、湖面微光为分层环境动画，适配减少动态效果的系统偏好。
- 中央 9·12 生日布置可用右上角开关关闭，选择在本浏览器保存。此布置为节日示例，不跟随当前日期自动开启。
- 「传统 BBS」是禁用的 UI 占位，尚未实现模式切换。
- 衣橱新增猫猫头套、辛普森、蝙蝠侠和 JOJO 星尘战士四款小龙造型；JOJO 使用高对比漫画墨线版本，底部快捷换装也可直接试穿。

点击地面、WASD 或方向键移动；点击目的地查看入口，靠近后按 E 进入；空格打招呼。

## 结构

- `src/data/town.ts`：场景坐标、四类入口、装扮和示例动态。
- `src/components/GameScene.tsx`：画面、相机、目的地交互与人物分层。
- `src/components/PlaceExperience.tsx`：四类入口的不同体验。
- `src/components/DailyBriefing.tsx`：日报。
- `src/components/AmbientLife.tsx`：环境动态。
- `src/hooks/`：移动、帖子、未读记录。
- `public/assets/plaza-integrated.png`：统一绘制建筑、地基和实体招牌的背景。
- `public/assets/seasonal/birthday-912.png`：独立透明节日布置。
- `archive/static-v1/`：最初静态版本留档。

所有发帖、回复、未读、装扮与活动选择仅保存在当前浏览器。人物和动态为示例内容，未接入多人服务器；匿名是前端展示逻辑。没有真实活动报名、消息推送或服务端匿名保障。
